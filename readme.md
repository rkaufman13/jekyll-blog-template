# Basic blog template in Jekyll

This is a 'starter kit' for running a blog with Jekyll. None of the Github-approved Jekyll themes are "out of the box" suitable for a blog, so if you are hoping to get started easily, try cloning this repo.

Setup steps:
Go to your new repo's settings on Github, choose "Pages," then click Github Actions. The action included in this repo should run automatically on new commits to main.

To blog:
Create a markdown file in `_posts`.
